Welcome to your new Quire site. This post lives in `content/posts/` and was
rendered from Markdown with YAML front matter.

## What you can do next

- Edit this post, or delete it and write your own
- Create a new post with `quire new post "My title"`
- Switch the theme in `quire.yml` from `blog` to `portfolio`
- Run `quire serve` and watch the browser reload as you edit

## Markdown features

Quire uses kramdown with GFM input, so tables, fenced code blocks and
footnotes[^1] all work. Code blocks get syntax highlighting:

```ruby
def hello(name)
  puts "Hello, #{name}!"
end
```

| Column A | Column B |
|----------|----------|
| one      | two      |

[^1]: Footnotes are supported too.
