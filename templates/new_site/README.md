# mysite

A site built with [Quire](https://github.com/nekonaru/quire).

## Commands

```bash
quire build     # build into public/
quire serve     # serve locally with live reload
quire clean     # remove public/ and the cache
quire new post "Title"    # new post
quire new page "Title"    # new page
```

Edit `quire.yml` to change the title, description, theme, menu, and base_url.
